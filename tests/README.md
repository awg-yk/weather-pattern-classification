# テスト

```powershell
python -m pytest tests -q
```

分割・重みの保存・ラベルと画像の対応づけ・ERA5の特徴量を対象にしている。
選んだ基準は「**壊れても正常に見えるもの**」。学習が止まるバグはログを見れば分かるが、
分割が壊れて学習画像で評価してしまう類のバグは、最後まで正常に完了して
実力より高い数字を出す。実際に最初の macro F1 0.75 はそれで出た値だった。

| ファイル | 守っているもの |
|---|---|
| `test_split.py` | 学習・検証・テストが重ならないこと、テスト年の前後が学習に残らないこと、同じ日の00Z/12Zが引き裂かれないこと |
| `test_model.py` | CoordConvが初期状態で従来と一致すること、重みの保存と復元、構成が食い違う重みを拒むこと |
| `test_dataset.py` | ラベル・画像・ERA5特徴量が行番号でずれないこと、画像の欠けを学習前に報告すること |
| `test_era5.py` | 緯度が降順でも領域を切り出せること、南寄りの高気圧ほど東寄りの風が強いこと |
| `test_review_sampling.py` | 層別抽出した見直し結果を本来の出現率に戻す計算が、その出現率で直接測った値と一致すること、戻し忘れると少数ラベルの上限を過大評価すること |
| `test_chartsymbols.py` | 天気図の色マスクが前線と海岸線を取り違えないこと、等圧線を記号候補に混ぜないこと、入れ子になった記号の誤検出を抑えること |
| `test_calibration.py` | 確信度の校正がpos_weightのかさ上げを戻せること、ラベル内の順位を変えないこと(＝F1とAPが変わらない根拠)、古い校正ファイルの取り違えを検出すること |
