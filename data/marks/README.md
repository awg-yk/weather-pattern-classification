# 中心の印(×)のテンプレート

**このディレクトリの中身は人が手で用意する。**

    cross.png  cross2.png ...           ただの×
    circle_cross.png ...                丸で囲んだ×

**印の形では高低を見分けない。**名前は自由でよい。種別はいちばん近い H/L の
文字から取る(`src/chartfeatures.assign_marks_to_letters`)。丸で囲んだ×を
テンプレートで拾おうとすると、図の側の丸の大きさがまちまちなので失敗する。

印は小さく丸い塊で、閉じた等圧線の内側にあって線と重なりにくいので、
`scripts/extract_symbols.py cut --box` がそのまま使える。

**このディレクトリが空だと、等圧線に横切られた H/L が拾えなくなる。**
弱いしきい値は印との裏書きがある場合にだけ効く設計のため、印なしでは
1枚あたりの検出が半分ほどに減る(実測で6個 -> 3個)。
