# H / L の文字テンプレート

**このディレクトリの中身は人が手で用意する。**機械では切り出せない
(`docs/2026-08-26-detection-prescreen.md`)。太い等圧線が記号の上を横切ると
連結成分では分けられないためで、人なら重なっていない個体を選べる。

    H.png  H2.png  H3.png ...      高気圧の「H」
    L.png  L2.png  L3.png ...      低気圧の「L」

* 天気図から**その文字だけ**を切り出す。周りの等圧線は消す
* **前線を含めないこと。**手で切り出した画像は濃淡で2値化するので、赤い前線も
  青い前線もインクとして入る。一方、天気図側は黒の帯だけで照合するので、
  テンプレートにだけ余分なインクがある状態になり一致スコアが下がる
* 白地に黒でも自動で反転する
* 末尾の数字は自動でまとめて数える(H2 も H_b も「H」として扱う)

実測では H 5枚・L 7枚で足りた。同じ記号でも汚れ方や重なり方が違うと外れるので、
別の個体からもう1枚作ると当たるようになる。
