# 保存済みラベルは、妥当な答えを取りこぼしている(2026-08-25)

2023年のテストセット60枚について、モデルの1位判定に人が○×を付け、
`data/labels_v2.csv` の判定と突き合わせた。

## 測ったこと

|  | ラベル上も正解 | ラベル上は不正解 |
|---|---|---|
| **人が ○** | 52 | **5** |
| **人が ×** | **0** | 3 |

- ラベルで測った正解率: **86.7%**
- 人の目での正解率: **95.0%**
- 取りこぼし: **5/60 = 8.3%**(95%区間 3.6%〜18.1%)

**逆向き(ラベル上は正解だが人は×)が0件。** 一方向であることが重要で、
これは「基準が違う」でも「人が甘い」でもなく、ラベルが妥当な答えを
落としている、という仮説だけが説明できる形になっている。

判定は「日本全域の気圧配置として妥当か」で行った。風替わりの日の選定に使った
「小松周辺の風替わりに効くか」という基準ではない。ラベル付けと同じ問いである。

## 原因の一つは、二つ玉低気圧の付け方

`data/labels_v2.csv` 全体を数えると:

```
二つ玉あり                        : 112件
  うち 日本海低気圧を併記          :   0件
  うち 南岸低気圧を併記            :   0件
```

**112件すべてで構成要素が併記されていない。例外はない。**
`scripts/label_stats.py` が記録しているとおり、これは意図的な運用
(個別の2ラベルを足すのではなく、置き換える)である。

しかし二つ玉低気圧は「日本海低気圧と南岸低気圧が同時にある」状態を指すので、
**天気図にはその両方が実際に写っている**。モデルが片方を答えると、正しく
読み取っているのに不正解と数えられる。取りこぼし5件のうち2件がこれだった。

```
2023-01-20 12Z  モデル=二つ玉低気圧(61%)  / 記録=前線通過|日本海低気圧
2023-06-22 00Z  モデル=南岸低気圧(100%)   / 記録=二つ玉低気圧|停滞前線
```

残る3件は、この規約とは無関係な単純な付け忘れだった。

```
2023-08-23 00Z  モデル=移動性高気圧(73%)  / 記録=太平洋高気圧型
2023-05-18 12Z  モデル=南岸低気圧(99%)    / 記録=移動性高気圧|停滞前線
2023-05-14 00Z  モデル=移動性高気圧(57%)  / 記録=二つ玉低気圧
```

## 影響

**報告している macro F1 は下限である。** どれだけ下振れしているかは、
top-1正解率での8.3%からそのまま換算できない(F1はラベルごとの適合率・再現率で
決まり、取りこぼしは主に適合率を押し下げる)。ただし向きは確実に一方向で、
実力を過小評価する側に働いている。

**確信度の校正も、この偏りを引き継いでいる。** 校正は labels_v2.csv を
正解として当てはめたので、「妥当なのに不正解と数えられた分」だけ確信度を
下げる方向に学習した。実際、2023年60枚では校正後の確信度が人の目に対して
低すぎる(50〜70%と表示した7件が実際には100%正しい)。

出発点の「明らかに違うのに確信度が高い」は、少なくとも日本全域の気圧配置と
いう基準では、この評価では起きていない。

## 決める必要があること

二つ玉低気圧を**合成ラベル**とみなすのか、**排他的な分類**とみなすのか。

- 合成とみなす → 112件に日本海低気圧・南岸低気圧を併記する。
  日本海低気圧 419→531件、南岸低気圧 255→367件になり、報告値はすべて出し直し
- 排他とみなす → ラベルは変えず、評価側で「二つ玉と構成要素は矛盾しない」と
  みなす。ラベルは動かないが、指標の定義が複雑になる
- 何もしない → 報告値は下限であると明記する

これは気象学的な定義の問題であって、実装で決められるものではない。

## 測り直す手順

```bash
python -m scripts.predict_charts --images-dir <画像> --labels data/labels_v2.csv \
    --weights runs/v2_chart_spread/model_test2023.pt --years 2023 --limit 60 \
    --out data/predictions_2023.csv

python -m scripts.grade_predictions --predictions data/predictions_2023.csv \
    --images-dir <画像> --out data/grade_2023.csv --against-labels data/labels_v2.csv
```

leave-one-year-out の重みでは、`--years` にその重みのテスト年だけを指定すること。

n=60 は取りこぼし率の区間が 3.6%〜18.1% と広い。方向は確定しているが、
大きさを詰めるには枚数がいる。
