# 前処理を作り直し、全期間を1つの設定に揃えた

2026-09-02

## きっかけ

2000〜2022年の天気図で高低気圧が1個も検出できなかった。当座の回避策として
「2023年を境に検出の設定を打ち分ける」を入れたが、利用者から
**「2023年を境に2つに分けるのはきれいではない」**と指摘を受けた。正しい。
場合分けは症状への対処であって、原因の解決ではない。

## 原因

`autocrop_to_content` は「非白の最大の連結成分」の外接矩形で切る。**紙の
大きさではなく、枠が紙のどこにどれだけの大きさで描かれているかで切り取り後の
大きさが決まる。**天気図の版面は時代で違うので、生が同じでも切り取り後が揃わない。

実測(生はどれも 2339x1653):

| 時期 | 切り取り位置 | 切り取り後 | 基準との差 |
|---|---|---|---|
| 2000〜2005年 | (426, 59, 1925, 1607) | 1499x1548 | +3.2% |
| 2006〜2011年 | (442, 78, 1896, 1575) | 1454x1497 | +0.1% |
| 2012〜2019年 | (442, 75, 1894, 1575) | 1452x1500 | -0.1% |
| 2020〜2025年 | (441, 75, 1895, 1575) | 1454x1500 | +0.1% |

ずれていたのは**2000〜2005年の6年分だけ**だった。

## 直し方

前処理に「切り取ったあと、決まった大きさへ揃える」を足した
(`scripts/preprocess_jma.CANONICAL_SIZE = (1453, 1500)`)。

基準を 1453x1500 にした理由は、`data/templates` と重みがこの縮尺で作られて
いるため。**気象庁PDF版はもともとこの大きさなので、その時代の画像は1画素も
変わらない。**同じ大きさのときは resize を素通しにしてある(補間で画素が
変わると、学習済みの重みに違う絵を渡すことになる)。

縦横比の差は0.033%しかないので、揃えても形は歪まない。

### 効果

2000-01-01の天気図、**しきい値0.65・テンプレート原寸のまま**:

    揃える前 1499x1548  H 0個 / L 0個
    揃えた後 1453x1500  H 3個 / L 4個

2023年以降の平均(H 2.8 / L 3.9〜4.2)と同水準。**時代の打ち分けも、
テンプレートの切り直しも不要になった。**利用者に切り出してもらった
`data/templates_ndl` は結局使わずに済んだ。

## 学習し直し

前処理を変えたので測り直した。データは国立国会図書館由来の17,898枚
(2000〜2025年)に一本化し、**学習と評価は2023〜2025年の2168件**に限った
(2026年は入れると区切りが悪いので外した)。

    python -m scripts.preprocess_jma --in-dir data/raw/new_png --out-dir data/processed/all
    python -m scripts.cross_validate --data-dir data/processed/all \
        --labels data/labels_v2.csv --years 2023 2024 2025 --out-dir runs/new_baseline
    python -m scripts.annotate_charts --in-dir data/processed/all \
        --out-dir data/processed/all_annot --years 2023 2024 2025 --no-fronts
    python -m scripts.cross_validate --data-dir data/processed/all_annot \
        --labels data/labels_v2.csv --years 2023 2024 2025 --out-dir runs/new_annot

1foldあたり約30分、1回3fold で1.5時間。

## 結果(これが発表に使う数字)

| | macro F1 | foldごと(2023/2024/2025) |
|---|---|---|
| 基準(天気図をそのままCNNへ) | 0.640 ± 0.013 | 0.646, 0.649, 0.625 |
| **検出結果を描き込んでからCNNへ** | **0.669 ± 0.004** | 0.674, 0.666, 0.669 |
| 差 | **+0.029** | +0.028, +0.017, +0.044 |

**3foldとも正。**自明な予測(全部陽性)は0.269なので、上積みは +0.371 と +0.400。

旧データでの測定(+0.021)より差が大きく、**ばらつきが 0.013 → 0.004 に
縮んだ。**描き込み方式は年によらず安定して効く。

### ラベル別

| ラベル | 基準 | 描き込み | 差 |
|---|---|---|---|
| オホーツク海高気圧 | 0.279 | 0.397 | **+0.118** |
| 日本海低気圧 | 0.647 | 0.705 | **+0.058** |
| 移動性高気圧 | 0.722 | 0.755 | +0.033 |
| 二つ玉低気圧 | 0.465 | 0.497 | +0.032 |
| 太平洋高気圧型 | 0.555 | 0.587 | +0.032 |
| 台風 | 0.867 | 0.896 | +0.029 |
| 停滞前線 | 0.755 | 0.774 | +0.019 |
| 南岸低気圧 | 0.609 | 0.612 | +0.003 |
| 前線通過 | 0.716 | 0.708 | -0.008 |
| 西高東低（冬型） | 0.784 | 0.764 | -0.020 |

10個中8個で上がった。**一番大きいのはオホーツク海高気圧**で、これは以前の
測定(0.270 -> 0.367、+0.097)より伸びている。

## 旧データとの照合

| | 旧 | 新 |
|---|---|---|
| 基準 | 0.647 ± 0.016 | 0.640 ± 0.013 |
| 描き込み | 0.667 ± 0.017 | 0.669 ± 0.004 |
| 差 | +0.021 | +0.029 |

基準の差0.007はばらつきの内側。**前処理を作り直しても成績は落ちていない。**
これは作り直しが正しく動いていることの確認でもある。

## 変わっていない結論

位置を入力として渡す(CoordConv)、出力として答えさせる(補助タスク)は
いずれも効かず、**絵として描くものだけが効いた**という説明はそのまま。
詰まっていたのは「どこにあるか」ではなく「そこに何かがあると気づくこと」。
伸びたラベルの筆頭が今回もオホーツク海高気圧であることと整合する。
