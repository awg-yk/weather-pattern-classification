# 正解率とラベル別の適合率・再現率

2026-09-03

## きっかけ

利用者から「macro F1 の 0.669 は、約66.9%の確率で当たるということか」と
聞かれた。**違う。**そして、指導教員も同じように読む可能性が高い。

macro F1 は適合率と再現率の調和平均を、10ラベルで**均等に**平均したもの。
「何%当たるか」ではない。数字の意味を取り違えたまま発表する方が、
指標が1つ足りないことより悪い。

`scripts/report_metrics.py` を作り、意味の違う数字を並べて出せるようにした。
**測り直してはいない。**必要な値は `runs/*/summary.json` に既に入っていた。

## 全体(2023〜2025年、3fold、2168枚)

| | 基準 | 描き込みあり | 差 |
|---|---|---|---|
| 1位正解率 | 81.6% ± 4.9 | **83.4% ± 4.7** | +1.8% |
| macro F1 | 0.640 ± 0.013 | **0.669 ± 0.004** | +0.029 |
| micro F1 | 0.681 ± 0.049 | 0.708 ± 0.015 | +0.027 |
| weighted F1 | 0.691 ± 0.031 | 0.717 ± 0.012 | +0.025 |

### 1位正解率をどう読むか

1枚に付く正解ラベルは平均1.65個で、1位がそのどれかに当たれば正解と数える。
つまり**多重ラベルなぶん、当たりやすい方に寄った数字**。下敷きと比べる:

| | 1位正解率 |
|---|---|
| でたらめに1つ選ぶ | 16.5% |
| 一番多いラベル(移動性高気圧)を毎回答える | 41.1% |
| 天気図をそのままCNNへ | 81.6% |
| **検出結果を描き込んでからCNNへ** | **83.4%** |

### macro F1 の上積みの方が大きい理由

1位正解率は +1.8% だが macro F1 は +0.029。**改善が出現の少ないラベルに
集中しているから。**1位正解率は件数の多いラベルに引きずられるので、
オホーツク海高気圧(188件)が良くなってもほとんど動かない。
macro F1 は10ラベルを1票ずつ数えるので、そこが効く。

どちらが正しいという話ではなく、**見ているものが違う。**

## ラベル別(描き込みあり)

| ラベル | 適合率 | 再現率 | F1 | 件数 |
|---|---|---|---|---|
| 移動性高気圧 | 83.7% | 70.9% | 0.755 | 891 |
| 停滞前線 | 82.6% | 77.4% | 0.774 | 665 |
| 日本海低気圧 | 65.0% | 77.7% | 0.705 | 368 |
| 前線通過 | 68.1% | 79.5% | 0.708 | 340 |
| 西高東低(冬型) | 69.7% | 84.9% | 0.764 | 312 |
| 台風 | 91.2% | 88.4% | **0.896** | 247 |
| 太平洋高気圧型 | 51.0% | 69.1% | 0.587 | 246 |
| 南岸低気圧 | 67.4% | 64.2% | 0.612 | 216 |
| オホーツク海高気圧 | 34.9% | 52.4% | **0.397** | 188 |
| 二つ玉低気圧 | 56.1% | 54.1% | 0.497 | 97 |

適合率 = 「このラベルだ」と言ったうちの当たり(空振りの少なさ)
再現率 = 実際にそのラベルだった日のうち拾えた割合(見逃しの少なさ)

### 外し方の傾向

**F1 だけでは、空振りが多いのか見逃しが多いのかが分からない。**
次に手を打つ先を決めるのはこの2つの差。

| 傾向 | ラベル |
|---|---|
| 言いすぎ(適合率 < 再現率) | 太平洋高気圧型 -18、オホーツク海高気圧 -18、西高東低 -15、日本海低気圧 -13、前線通過 -11 |
| つり合っている | 二つ玉低気圧、台風、南岸低気圧、停滞前線 |
| 慎重すぎ(適合率 > 再現率) | 移動性高気圧 +13 |

**オホーツク海高気圧は「言いすぎ」。**適合率34.9%なので、そう判定した
3回に2回は外している。件数が188件と少ないうえ、`pos_weight` で少数ラベルを
かさ上げしているぶん、陽性側に倒れやすい。

## ラベル別の差(描き込みで何が変わったか)

| ラベル | 基準 | 描き込みあり | 差 |
|---|---|---|---|
| オホーツク海高気圧 | 0.279 | 0.397 | **+0.118** |
| 日本海低気圧 | 0.647 | 0.705 | +0.057 |
| 移動性高気圧 | 0.722 | 0.755 | +0.032 |
| 二つ玉低気圧 | 0.465 | 0.497 | +0.032 |
| 太平洋高気圧型 | 0.555 | 0.587 | +0.031 |
| 台風 | 0.867 | 0.896 | +0.028 |
| 停滞前線 | 0.755 | 0.774 | +0.020 |
| 南岸低気圧 | 0.609 | 0.612 | +0.003 |
| 前線通過 | 0.716 | 0.708 | -0.008 |
| 西高東低(冬型) | 0.784 | 0.764 | -0.020 |

**10個中8個で改善。**下がった2つは元々よくできていたラベル(0.716・0.784)。

二つ玉低気圧は中身の変わり方が大きい: 適合率 69.7%→56.1%、再現率
39.3%→54.1%。**枠を描いたことで「2つの低気圧」を見つけられるように
なった代わりに、言いすぎるようにもなった。**F1 は +0.032。
