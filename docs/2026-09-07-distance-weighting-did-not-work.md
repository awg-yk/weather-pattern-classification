# 地点の近さで重み付けする案は、おろし風には当てはまらなかった

2026-09-07

## やろうとしたこと

考察③(モデルが日本全体を見て判断するため、小松に影響しない遠方の気圧配置
まで拾ってしまう)への対策として、**小松の近くにあるものを重く見る**仕組みを
2通り作った。

1. 検出した高低気圧を、小松からの距離で絞り込む / 重み付けする
2. Grad-CAM の熱を小松への近さで重み付けし、ラベルの順位を付け替える

## 結果: 前提が成り立たなかった

**「小松に近い気圧配置ほど、小松のおろし風に効く」という前提が誤りだった。**
利用者(予報官)の確認による。**離れていてもおろし風に作用する系がある。**
おろし風は山越えの下降流なので、駆動しているのは離れた場所にある系が作る
気圧傾度であり、小松の近くに中心があるとは限らない。

実測もこれと整合していた。

### 円で切った場合(半径0.12 ≒ 430km)

167日のうち**周辺に高低気圧の中心が1つも無い日が143日(85.6%)。**
167日を合計しても周辺の高気圧は5個、低気圧は23個しかない。

しかもこの85.6%の大半は「円が小さいから」で説明がついてしまう。円は天気図の
4.5%しかなく、系が一様にばらまかれているだけでも77.5%は0になる計算になる。
**指標として差が付いていなかった。**

### 距離で滑らかに重み付けした場合

円の崖は無くなり(距離0.13の熱は円では0.000、距離では0.300)、順位も動く
ようになった。しかし**動いた先が予報官の見立てと合わない。**近さを効かせる
ほど、実際にはおろし風に効いている遠方の系が沈む。

## 学んだこと

**「地点に近いほど重要」は、地点特有の現象すべてに使える前提ではない。**
局地的な現象でも、それを駆動しているのは総観規模の配置であることがある。
おろし風はその典型で、山越えの風は風上側の気圧配置で決まる。

冬型でこれがはっきり出る。冬型の根拠は西の高気圧と東の低気圧の配置であって、
小松の近くにあるのは混んだ等圧線だけである。近さで重み付けすると、**正しく
冬型と判定している日ほど不利になる。**

## 作ったものは残す

仕組み自体は動いており、**別の現象や別の地点では有効かもしれない**ので残す。
`data/sites.csv` に1行足せば他の地点でも試せる。

    src/sites.py              地点と、円 / 距離の重み
    scripts/site_preview.py   位置合わせの目視確認(--grid で目盛り)
    scripts/site_report.py    日付一覧に対する周辺の系の集計
    src/quicklook.rerank_*    Grad-CAM の熱で順位を付け替える
    notebooks/oroshi_komatsu.ipynb  167日をまとめて処理する

## 次にやるなら

距離を前提に置かず、**どこを見るべきかをデータから決める**方向になる。
167日には人間による判断があるので、それを教師にして「おろし風に効く領域」を
当てはめることは原理的にはできる。ただし167件は少なく、季節や型で分けると
さらに減る。**発表(2026-09-14)までの規模ではない。**

方角で重み付けする案(おろし風の風上にあたる方向を重く見る)も考えられるが、
これも「どの方角を重く見るか」を決める根拠が要る。
